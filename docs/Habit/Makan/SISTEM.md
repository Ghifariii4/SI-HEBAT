# 🥗 SISTEM CHECKLIST MAKAN SEHAT

Target desain:
- Mendorong pola makan bergizi seimbang
- Tidak memberatkan siswa
- Tidak bisa farming XP
- Seimbang dengan sistem ibadah & olahraga

---

# 1. STRUKTUR MAKAN (3x SEHARI)

Maksimal input:
- Sarapan
- Makan Siang
- Makan Malam

Tidak bisa input lebih dari 3 kali per hari.

---

# 2. 4 UNSUR GIZI WAJIB DIISI

Dalam 1 kali makan terdapat 4 unsur:

1. Karbohidrat
2. Protein
3. Sayur
4. Buah

User wajib mengisi minimal **2 unsur** agar dihitung.

Contoh input:
- Karbo: Nasi
- Protein: Ayam
- Sayur: Bayam
- Buah: Pisang

---

# 3. SISTEM XP MAKAN

Base XP (minimal 2 unsur terisi):
→ 10 XP

Jika isi 3 unsur:
→ +5 XP

Jika isi lengkap 4 unsur:
→ +10 XP

Maksimal 1 kali makan:
→ 20 XP

Jika 3 kali makan lengkap:
→ 60 XP

---

# 4. MINUM AIR PUTIH

Target harian: 8 gelas

User input jumlah (1–8), tidak dicentang satu-satu.

## Skema XP Air Minum

| Jumlah Gelas | XP |
|--------------|----|
| 1–3 gelas | 0 XP |
| 4 gelas | 10 XP |
| 6 gelas | 15 XP |
| 8 gelas | 25 XP (maks) |

Maksimal XP minum per hari:
→ 25 XP

---

# 5. FOTO MAKAN (OPSIONAL)

- Maksimal 1 foto per hari
- Tidak wajib
- Harus foto di hari yang sama
- Tidak menambah unsur gizi

Bonus:
→ +10 XP (jika ACC Guru)

---

# 6. BONUS HARI SEMPURNA

Jika dalam 1 hari:
- 3x makan lengkap (4 unsur)
- 8 gelas air terpenuhi

Maka mendapat:
→ +15 XP bonus tambahan

---

# 7. BATAS HARIAN

- Maks 3 makan
- Maks 8 gelas air
- Maks 1 foto
- Maksimal XP makan sehat per hari:
  → 95 XP

Rincian maksimal:
- 60 XP makan
- 25 XP minum
- 10 XP foto
- 15 XP bonus sempurna

---

# 8. ANTI ABUSE SYSTEM

- Minimal 2 unsur agar dihitung
- Tidak bisa input makan lebih dari 3
- Tidak bisa input air lebih dari 8 gelas
- Foto hanya 1x per hari
- Semua waktu mengikuti server time

---

# 9. TUJUAN SISTEM

- Membiasakan makan bergizi seimbang
- Mendorong konsumsi air cukup
- Mengedukasi tentang komposisi makanan sehat
- Memberi reward pada kualitas, bukan kuantitas
