# SISTEM CHECKLIST TIDUR MALAM

Target desain:
- Membentuk disiplin tidur
- Mengurangi kebiasaan begadang
- Sistem tegas tetapi tidak berlebihan
- Terintegrasi dengan sistem bangun pagi

--------------------------------------------------

1. DEFINISI HARI SISTEM

Hari sistem dimulai pukul 03:00 dan berakhir pukul 02:59.

Artinya:
- Input tidur hanya bisa dilakukan antara 19:00 – 02:59
- Pukul 03:00 sistem reset ke hari baru
- Jika belum input sampai 02:59 maka dianggap tidak mengisi (0 XP)

--------------------------------------------------

2. PEMBAGIAN WAKTU

Sebelum 19:00
Tidak bisa mengisi (popup: "Belum waktunya tidur malam")

19:00 – 21:59
Waktu ideal

22:00 – 22:59
Terlambat ringan

23:00 – 23:59
Begadang sedang

00:00 – 01:59
Begadang berat

02:00 – 02:59
Sangat larut

03:00
Form tertutup dan reset hari

--------------------------------------------------

3. SISTEM XP

19:00 – 21:59
+50 XP

22:00 – 22:59
+40 XP

23:00 – 23:59
+30 XP

00:00 – 01:59
+15 XP

02:00 – 02:59
0 XP

--------------------------------------------------

4. ATURAN BEGADANG

Jika tidur setelah 22:00:

Wajib memilih alasan:
- Tugas Sekolah
- Belajar
- Acara Keluarga
- Sakit
- Main Game / Sosial Media
- Lainnya

Jika tidak memilih alasan:
- Tetap tercatat
- Dikenakan -10 XP penalti

Foto tidak wajib.

--------------------------------------------------

5. SISTEM LOCK

Setelah menekan tombol "Selamat Tidur":

- Semua menu kebiasaan lain terkunci
- Tidak bisa input aktivitas lain
- Dashboard dinonaktifkan sampai pukul 03:00
- Jika logout dan login kembali tetap terkunci

Tujuan:
Mencegah manipulasi setelah deklarasi tidur.

--------------------------------------------------

6. PENGINGAT DOA

Sebelum tombol konfirmasi aktif, muncul popup:

"Sudahkah kamu berdoa sebelum tidur?"

Pilihan:
- Sudah
- Ingatkan saya

Setelah konfirmasi baru bisa menekan tombol "Selamat Tidur"

--------------------------------------------------

7. BATASAN SISTEM

- Hanya bisa input 1 kali per hari
- Tidak bisa mengedit setelah dikonfirmasi
- Mengikuti waktu server
- Tidak bisa mengisi sebelum 19:00
- Tidak bisa mengisi setelah 02:59

--------------------------------------------------

8. TUJUAN SISTEM

- Membentuk kebiasaan tidur sehat
- Mengurangi begadang
- Melatih tanggung jawab waktu
- Membiasakan doa sebelum tidur
- Meningkatkan kedisiplinan harian
